# DAMN

**Doomscrolling Against Mandatory Notifications.** *Log off. Violently.*

An original, fully offline, 90s-style first-person shooter for the browser, absolutely saturated with extremely online comedy. Powered by [VANILLAJS](https://github.com/QSOLKCB/VANILLAJS) and [OPT](https://github.com/QSOLKCB/OPT). No engine, no frameworks, no image or audio files, no network: every wall, monster, gun, sound, song and bad joke is generated by the game's own code.

> The Algorithm went sentient. The comment section leaked into reality. You are the last person who reads the terms and conditions. Find the admin passwords, fight through three tabs, and hit **LOG OFF**.

## Play

Serve the folder with any static server (ES modules don't load from `file://`), open it once, and wait for **OFFLINE READY**. After that, the same address works with the network unplugged.

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.

| Action | Keys |
| --- | --- |
| Move / strafe | W A S D |
| Turn | Mouse (click the game to capture it) or ← → |
| Fire | Left click or Ctrl |
| Use doors, switches and suspicious walls | E or Space |
| Walk (always-run is on by default) | Shift |
| Weapons | 1–6, mouse wheel, Q |
| Automap | Tab |
| Pause / mute | Esc or P / M |

## The tabs

1. **The Comment Section.** *Where nuance goes to die.* Find the RED password (it's `hunter2`).
2. **The Server Farm.** *It is always 3 AM in here.* BLUE opens the east wing; RED opens the exit.
3. **The Algorithm.** *It knows what you did. It recommended it.* Get the YELLOW password, then uninstall the boss.

Every tab has secrets: hidden walls that slide away with E (you'll hear dial-up), and secret tiles that count toward your grade. The intermission grades you from *D / SKILL ISSUE* to *S / TOUCHED ALL THE GRASS* and asks whether you saved any screen time.

## How it's built

| File | What it does |
| --- | --- |
| `src/game.js` | Pure fixed-step simulation: grid collision, sliding doors, password doors, hidden walls, hitscan and projectiles, splash with line of sight, enemy AI (sight, sound propagation through open space, a shared flow field, door opening, pain and attack wind-ups), boss summons, pickups, secrets and stats |
| `src/renderer.js` | Software raycaster into a chunky low-res `ImageData`: textured walls, inset sliding doors with jambs, perspective floor and ceiling casting, distance fog, depth-tested sprites, weapon viewmodel, pixel-font HUD, speech-bubble barks and automap |
| `src/art.js`, `src/font.js` | Every texture and sprite drawn procedurally into pixel arrays, plus an original 3×5 bitmap font |
| `src/audio.js`, `src/music.js` | Synthesized effects (yes, the hidden walls play dial-up) and an original 152 BPM chip-metal score that intensifies in fights |
| `src/maps.js` | The three tabs as editable ASCII, with a legend at the top |
| `src/clock.js`, `src/frame-gate.js` | VANILLAJS `FixedClock` (120 Hz real-time ticks) and `FrameGate`, which skips redrawing static pause, intermission and death screens |
| `sw.js` | Scope-isolated offline cache |

From OPT: art is generated once, and the framebuffer and depth buffers are reused every frame (OPT-INV-001). The enemy flow field is shared and recomputed only when you change cell or a door moves. A deterministic-replay and CPU-budget test (OPT-BUDGET-001) simulates a scripted minute of every tab.

## Develop

Node 22+ is only needed for checks. There's no `npm install`.

```bash
npm test
```

```bash
npm run check
```

```bash
npm run build
```

- **`npm test`** runs 23 tests:
  - Map validation, including a key-aware reachability solver that proves every item is reachable and every exit needs its passwords or the boss.
  - Doors, passwords, hidden walls, hitscan and occlusion, splash and chain explosions, enemy wake-up and armor, difficulty scaling, pickups, the boss, AI routing and deaths.
  - Deterministic replays and the CPU budget.
  - Art coverage, and that the pixel font can print every joke.
- **`npm run check`** checks syntax, rejects any remote URL or import, and makes sure every runtime file is in the offline cache list.
- **`scripts/browser-check.cjs`** (Playwright, CI only) plays the packaged build in Chromium and saves screenshots to `artifacts/`. It walks the menus, opens doors, fires, checks the automap and weapons, verifies the paused frame is gated, exits a tab, sees the intermission, plays tabs 2 and 3, dies, then reloads with the network off.

To add a level, draw it in `src/maps.js` using the legend; `npm test` tells you if anything is unreachable. The included workflow tests everything and deploys `dist/` to GitHub Pages on pushes to `main` (enable **Settings → Pages → Source → GitHub Actions** once).
